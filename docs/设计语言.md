# 小满记账 · 设计语言基线（2026-11-17）

> 目标：品牌色、UI、logo 是我们的；版式语言学一木可用，但组件规范自成一套，不再零散写样式。
> 所有页面样式必须从 `src/ui.css` 的令牌取值，`npm run check` 会拦裸色值、裸字号、裸圆角。

## 一、令牌

### 颜色
| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#fef9f3` | 页面底色（暖米） |
| `--card` / `--surface` | `#fffdf9` | 卡片、行容器 |
| `--surface-2` | `--accent-soft` | 区块内的浅色块（净资产 banner、徽标） |
| `--ink` | `#5a3a1e` | 正文 |
| `--muted` | `#8a6a50` | 次要文字、分组标题 |
| `--line` | `#f0e4d2` | 分割线、描边 |
| `--accent` | `#e0a53c` | 品牌主色（琥珀） |
| `--accent-soft` | `#fdf1db` | 主色浅底 |
| `--focus-ink` | `#9e5823` | 主色文字态（徽标、链接强调） |
| `--out` / `--in` | `#c2410c` / `#3f6212` | 支出 / 收入 |
| `--danger-ink` | `#a9452c` | 危险操作文字 |

### 间距（本轮补全）
`--sp-1: 4px` · `--sp-2: 8px` · `--sp-3: 12px` · `--sp-4: 16px` · `--sp-5: 24px` · `--sp-6: 32px`
规则：页面左右用 `--page-pad`(16)；卡片内边距 `--sp-4`；卡片之间 `--sp-3`；标签与值之间 `--sp-2`；同一行元素间距 `--sp-2`。

### 字号（6 档，禁止裸值）
`--font-xs` .75rem 辅助说明 · `--font-sm` .875rem 行文本 / 次要值 · `--font-md` 1rem 正文 · `--font-lg` 1.25rem 小标题 / 关键数字 · `--font-xl` 1.5rem 区块数字 · `--font-display` 2rem 页面主数字（净资产、记账金额）

### 圆角（4 档）
`--r-sm` 6px 小徽标 · `--r-md` 10px 卡片、输入框、按钮 · `--r-lg` 16px 大区块（banner、子页卡片）· `--r-pill` 999px 胶囊、头像、开关

### 阴影
`--shadow-1` 卡片静置 · `--shadow-2` 弹层 / 悬浮

## 二、组件规范

| 组件 | 规则 |
|---|---|
| 卡片 `.card` | 底色 `--card`、圆角 `--r-md`、内边距 `--page-pad`、`--shadow-1`；页面主级用 `.card`，子页用 `.card.subpage` |
| 页内分组 | 每组一张卡：`h3` 小灰字标题（`--font-xs` + `--muted`）+ 内容；不要再套白底卡片 |
| 行 `.row` | 高度 `--row-h`(50)，左侧图标 22、中间标题（+可选小字副标题）、右侧值/状态，尾随 `›` |
| 图标格 `.my-grid-item` | 竖排：图标 26 + 文案 `--font-sm`，无边框，点击态用 `--accent-soft` |
| 胶囊 `.chip` | 圆角 `--r-pill`，高度 `--h-control`，选中态主色描边 |
| 输入 `input/select/textarea` | 由 `:where()` 基线统一外观（白底、1px `--line`、圆角 `--r-md`、聚焦 `--ring`），类名可覆盖 |
| 下拉 | 一律使用 `SelectSheet` 或全局 `SelectShim`，禁止系统原生下拉可见 |
| 弹层 `.sheet` | 底部弹层：圆角 `--r-lg` 顶部、`--shadow-2`、列表项 48 高、选中打勾 |
| 主按钮 | 主色底 + `--on-accent` 文字，圆角 `--r-md`，最小高 `--h-control`；次按钮 ghost 描边 |
| 数字 | 金额统一 `¥` 前缀 + 两位小数；主数字用 `--font-display` + 600；支出 `--out`、收入 `--in` |

## 三、页面结构

1. **一级页**：`h2.page-title`（必要时隐藏，如「我的」）+ 若干卡片分组。
2. **子页**：`‹ 返回…` + `h3` 标题 + 内容，顶部滚动到 0，`screen` 状态由父级持有。
3. **行内操作**：列表行只承担「打开详情」，编辑/删除/复制等放在详情页，避免小屏误触（一木同款取舍）。
4. **只读态**：命令层拒绝 + 按钮禁用 + 明确提示三件套，缺一不可。

## 四、本轮修掉的设计基建问题

| 问题 | 影响 | 处理 |
|---|---|---|
| `--sp-1…4`、`--surface`、`--surface-2`、`--on-accent`、`--accent-ink`、`--nav-h` 被引用但从未定义 | 资产页、会员条、同步徽标的 padding/gap 全部失效，元素挤在一起 | 在 `:root` 补齐间距阶梯与面层令牌 |
| `.asset-banner` / `.asset-net-value` 等整块规则重复两遍 | 后一份覆盖前一份，改样式容易改错地方 | 删除重复块 |
| `button.asset-net-value` 被 `.link` 的字号覆盖 | 净资产主数字显示成正文大小，失去层级 | 提高选择器权重到 `button.` 并加字重 |
| 我的页会员条按钮压字、日历格金额溢出 | 版面破相 | 已在前几轮修复（flex 布局、超万显示「万」） |
