## 仍需注意的残余问题（本次未解决）

1. **#3 的引用重映射**：改号后不更新其他记录对它的引用（例如账单里的 `assetId`）。收敛问题已解决，但"引用指向错误账户"在极端碰撞下仍可能发生。根本解法是服务端统一分配记录身份。
2. **#5 的并发窗口**：两台设备在都未生成、且同时在线补生成时，会出现两条不同 UUID，靠拉取后的去重收敛。若其中一台在去重前就删除账单，仍可能留下墓碑冲突。
3. **#7 未做线上实测**：旧接口是死代码（客户端已用 `/api/data/*`），建议下一轮直接删除而不是只加鉴权。
4. **手工记账的外币快照是完整的**（`src/store.ts:195` 写入 `accountAmount`），所以 #6 只影响周期生成路径。
