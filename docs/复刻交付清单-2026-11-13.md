# 一木记账复刻交付清单（2026-11-13）

判定标准：除 UI/图标与非记账类外全部 1:1 复刻；商业化入口保留并提示「敬请期待」；平台限制例外。

## 三、平台/能力限制（未做，标注原因）

| 项 | 原因 |
|---|---|
| 扫一扫（QrCodeScanActivity） | 需摄像头扫码识别服务；网页端 BarcodeDetector 兼容性差 |
| 桌面小组件（widget_setting） | Android 桌面能力，网页不可替代 |
| 本地 MCP | 一木自有的本地 AI 能力，非记账功能 |
| 应用备案号 | 需工信部备案主体，当前显示「—」 |
