# 一木 Android 端布局（静态逆向，6.7.2）

来源：`apk-src/resources/res/layout/*.xml` + `adapter/CategoryPagerAdapter.java`。
**仅静态确认控件与尺寸**；动态显示条件、皮肤、动效需真机验证。

## 1. 首页：单列（不是网页版多栏压缩）

```
账本▾ 搜索 更多
本月支出 / 本月收入 / 本月结余·剩余预算
[ 添加一条新记账 ]      ← 45dp
今天 / 星期        收·支
  分类 备注 金额 账户
昨天 / 日期 …
```

- `fragment_home.xml`、`item_home_header.xml`
- 底部导航/浮动按钮在 XML 中**默认隐藏**，由运行时配置决定是否显示

## 2. 记账页：分类在上，输入区 + 键盘固定在下

```
返回  支出 收入 转账  账本
    分类图标网格（5 列，父 40dp / 子 32dp）
标签 备注 金额
日期 账户 报销 附件 优惠 属性 手续费
数字键盘（220dp，四则运算 + 再记 + 完成）
```

- `activity_add_bill.xml`、`layout_number_input.xml`、`item_transfer.xml`
- 转账是独立录入结构（转出/转入/余额/到账金额）
- 键盘有第二套布局，运行时可能不同

## 3. 账单列表：日期头 + 两种密度

- 日期头含：日期、`今天`、星期、当日收入/支出
- 普通行：图标、分类、金额、账户、时间、备注
- 详细行额外含标签、地址、附件
- `item_bill_main_list.xml`、`item_bill_main_detail_list.xml`

## 4. 账单详情：顶部摘要 + 分组 + 底部固定操作

- 顶部：图标、分类、金额、报销状态
- 中部：创建用户、币种、优惠、退款、日期、账户、报销、备注、标签、附件
- 后部：所属账本、记录时间、记录方式、关联账单
- 底部固定操作：报销 / 退款 / 编辑（按状态出现）
- `activity_bill_info.xml`

## 5. 统计与搜索

- 统计：日常 / 月统计 / 年统计 / 自定义；月统计含收支图、分类图、按日报表、账户与标签
- 搜索：输入、筛选、历史、结果数、收支汇总、空态
- `fragment_statistics.xml`、`fragment_statistics_month.xml`、`activity_bill_search.xml`

## 对小满的取舍

| 项 | 采纳 | 说明 |
|---|---|---|
| 分类可滚动 + 输入区固定底部 | ✅ | 移动端金额始终可达 |
| 5 列分类网格 | 参考起点 | dp 数值不必照搬，按屏宽验证 |
| 日期头含当日收支 | ✅ | 我们现在只有日期 |
| 紧凑行 + 详情承载完整信息 | ✅ | 记账人只在详情 |
| 底部固定操作区 | ✅ | 删除加二次确认 |
| 日期头显示"今天/昨天" | ✅ | 已确认一木这样做 |

优先级：**移动首页 → 记账页 → 账单详情 → 统计与搜索**。
