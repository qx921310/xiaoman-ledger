# 品牌信息（给设计/Codex）

| 项 | 值 |
|---|---|
| 中文名 | **小满记账** |
| 英文名 | Xiaoman Ledger（备用：Xiaoman） |
| 标语 | 小有盈余，日子清楚 |
| 主色 | 琥珀黄 `#E0A53C`（浅底 `#FDF1DB`） |
| 辅色 | 奶油底 `#FEF9F3`、深棕文字 `#5A3A1E`、次要 `#8A6A50` |
| 语气 | 克制、温和、不炫技；不写"智能""AI""极速"这类营销词 |

## 命名由来

「小满」是二十四节气之一，麦粒渐满而未熟——**小有盈余，不必求满**。
恰好是记账想达到的状态：不是让你暴富，是把日子记清楚。

## 需要更新的素材

1. **横版 logo**：当前 `brand/logo.svg` 里是占位字样「记账」，需替换为「小满记账」三字。
   建议中文用较厚重、圆润的黑体（类思源黑体 Bold），字距略松；图形标在前、文字在后。
2. **单色横版**：`logo-mono.svg` 目前是图形标，若能出一版含文字的单色横版更好。
3. **App 图标**：`app-icon-512.png` 目前是金币+账本，可保留；如需加"满"字暗纹请轻量。

## 不要做的

- 不要用「青」「绿」等冷色系（与暖黄主题冲突）
- 不要出现银行卡/支付宝/微信等第三方品牌图形
- 不要把吉祥物细节堆太多（32px 会糊）
