## 三、跑通过程中修掉的问题

```
1 staging 的 cookie 注入（Secure 未声明）→ 脚本回退到 UI 表单登录
2 表单登录误用生产账号 → 显式传 ACC_EMAIL / ACC_PASSWORD
3 日期格用 startsWith('3') 误命中 30 号 → 改为精确匹配日期数字
4 staging 日志断言失败 → 定位为 staging 未部署最新构建（缺 cal-daysum），部署后通过
```

## 四、已知限制 / 未覆盖

```
1 browser 插件（browser_click）对底部导航点击不生效，真机走查统一用 CDP；插件用于截图与 DOM 检查
2 iOS 微信 WebView 的 cookie 持久化、后台被杀后补传重放：本机无法验证
3 弱网 / 断网恢复、真机手势（长按、滑动）未做自动化
4 账户详情页 hero 只做了令牌核对，未逐帧对照 s22–s25
5 staging 账号存在 1 条历史待核对记录（与本次走查无关）
```
