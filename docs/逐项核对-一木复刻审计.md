## 四、接口架构差异（有意为之）

一木按实体划分 34 个端点（`/bill/addOrUpdateBill`、`/asset/deleteAsset` …）。我们采用**同步管道**：

```
POST /api/data/push   +  GET /api/data/pull     （增量、按记录 LWW）
POST /api/files                                  （附件）
/api/auth/*  /api/books/*                        （账号与账本）
```

差异原因：一木的实体端点需要服务端做业务校验与编号分配，我们把这些放进同步合并层（`domain/sync-merge.ts` + `domain/identity.ts`），换来离线可用。

**这是一次有意的架构取舍，不是漏做。**

## 六、结论

- **字段层面：无功能性缺失**，剩余为命名差异与展示型字段
