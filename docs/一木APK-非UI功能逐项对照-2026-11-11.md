## 优先交给 DSH 的处理建议

1. **先保证现有财务数据正确**：修复编辑时优惠和分摊不保存；复核退款、报销、转账、周期冲突、账本权限和余额联动。每条要覆盖创建、修改、删除、重开、两端同步，不能仅看字段或界面。
2. **按用户需求决定业务范围**：统计周/年/自定义，周期转账，退款编辑，信用卡/分期、AA 群组分别估算并确认顺序；不要直接把 Android 功能当作本 Web 项目必做项。
3. **对账口径先定规格后编码**：写明金额币种、退款冲减日期、转账手续费、报销到账、期号冲突，以及各场景账户余额和统计预期。比较账单、账户流水和统计三个视图。
4. **创建证据驱动的验收台账**：每一条记录 APK 版本、进入步骤、输入、结果、截图或测试数据；同样步骤跑小满并记录实际结果。通过只针对具体场景，不宣布整个模块百分百完成。
