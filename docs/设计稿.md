# 青账 · 设计稿 v0.1

> 目标：**功能与操作习惯对齐一木记账**，视觉另做。
> 本文只约束结构、流程、组件与令牌，不含视觉风格定稿。

---

## 1. 设计原则

| # | 原则 | 落地方式 |
|---|---|---|
| 1 | **记账 3 秒内完成** | 打开即在「记账」页；金额输入框自动聚焦；分类一屏可见；账户默认上次 |
| 2 | **一屏一件事** | 五个一级页，每页只承担一个任务，不做仪表盘堆叠 |
| 3 | **数字必须可信** | 任何改单/删除都要冲正账户余额；转账不算收支；手续费单独成账 |
| 4 | **迁移友好** | 直接吃原产品的导出文件；导完能对账（改余额） |
| 5 | **不给用户惊喜** | 分类沿用一木命名，避免迁移后重新学习 |

## 2. 信息架构

```
青账
├── 记账（默认落地页）
│   ├── 支出 / 收入 / 转账 三段切换
│   └── 金额 → 分类 → 子分类 → 账户 → 时间 → 备注
├── 账单
│   ├── 月份切换 + 收入/支出/结余汇总
│   ├── 筛选：关键词 / 分类 / 账户
│   └── 单行操作：改（弹层）/ 删
├── 资产
│   ├── 净资产 / 负资产
│   ├── 账户列表（按类型分组）
│   └── 改余额（弹层）/ 新增账户
├── 统计
│   └── 按月支出构成（条形 + 占比）
└── 设置
    ├── 迁移：选文件 / 载入示例 → 预览 → 确认
    ├── 导出：Excel / JSON
    └── 数据：演示数据 / 清空
```

**弹层（全局）**：改账单、编辑账户、Toast。
**不做**：底部 Tab（桌面/移动共用一套顶部导航）。

## 3. 核心流程

### 3.1 快速记账（目标：≤3 秒）

```
打开 → [记账页] 金额输入已聚焦
     → 输入 3250        （键盘/九宫格）
     → 点「食品餐饮」    （一屏 8 个大类，不需要滚动）
     → 点「午餐」        （可选，不选也能存）
     → 点「记一笔」      （账户默认上次使用）
     ✓ Toast：支出 ¥32.50 已记录
```

- 分类默认选中**上次使用的分类**（当前实现是首个，待补）
- 金额为空时按钮禁用，不做二次确认

### 3.2 改单（含冲正）

```
账单行「改」→ 弹层（金额已全选，可直接覆盖）
  → 保存
  → 系统：撤回旧账单对账户的影响 → 按新值重新记一次
  → 若换了账户：旧账户 +旧值，新账户 -新值
```

### 3.3 迁移

```
设置 → 选择文件（.xlsx/.xls/.csv）
  → 解析表头，识别来源（一木导出 / 转账流水 / 通用表）
  → 预览：总行数 / 可导入 / 重复 / 无法解析 / 收支合计 / 新增分类账户
  → 确认导入
  → 账单落库 + 逐笔冲账户 + 缺失分类账户自动创建
  → 去资产页把每个账户改成实际余额
```

### 3.4 对账

```
资产页 → 某账户「改」→ 输入实际余额（留空＝不变）→ 保存
净资产实时重算
```

## 7. 图标规范

**必须遵守**：不复制原产品美术资源。一木的图标是其版权资产，我们只复用**语义命名**。

- 命名：`ic_parent_<semantic>`（大类）、`ic_<group>_<semantic>`（二级），与本文第 8 节表格一一对应
- 规格：24×24 线性图标，2px 描边，圆角端点；选中态可填充
- 交付：SVG 单色（`currentColor`），由 UI 侧着色；当前代码用 emoji 占位
- 备选方案：直接用开源图标集（Lucide / Tabler）按语义键映射，最快

## 10.5 登录与同步（已定方案）

- **鉴权**：httpOnly Cookie 会话（方案 A）。密码服务端 `scrypt` + salt，绝不明文/可逆。
  **不照抄原产品的客户端 AES**——它的密钥内嵌在 bundle 里，属于混淆而非加密。
- **注册/登录**：仅邮箱 + 密码，不接手机号、不接第三方。
- **首次登录合并**：本地已有记账数据时，弹窗询问「是否同步到当前账本」；
  选择“否”则不同步，本地数据保留在原处。
- **重复判定**：时间 + 金额 + 类别 完全相同视为潜在重复；同步结束前汇总询问「覆盖 / 新增」。
- **同步策略**：增量推拉，按记录 `updateTime` last-write-wins，不做字段级合并。
