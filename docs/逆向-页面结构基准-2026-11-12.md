# 一木记账：页面结构基准（采证记录）

来源：`research/yimubill/apk-src`（反编译源码 + `resources/res/layout`）。
用途：作为「1:1 复刻」的事实基准。**未采证的项一律标注，不做推测。**

## 1. 首页 `fragment_home.xml`

```
RelativeLayout parent_layout
├─ tip_layout                 提示条（tip_image + 文案）
├─ DrawerLayout              右侧抽屉
│   ├─ JellyRefreshLayout → RecyclerView data_list     账单列表（可下拉刷新）
│   └─ right_drawer_layout
└─ BlurView tool_bar          浮动工具栏
    ├─ account_book_layout   账本图标 + 账本名            ← 当前账本在首页可见
    └─ tool_bar_right_layout
        ├─ month_range_layout 月份范围文字 + 箭头
        ├─ spin_kit           加载指示
        ├─ btn_add_bill       加账单
        ├─ btn_search         搜索
        └─ btn_more           更多
```

列表项（`item_bill_common_list.xml` / `item_bill_capital_flow.xml` / `item_bill_child_type.xml`）：

```
日期头：date_text + week_info + income + pay
账单行：icon + category + 金额（含 reimbursement/refund/discount 标记）
汇总行：total_layout + icon + name（分类小计）
```

首页点击行为（`HomeFragment.java` 的 @OnClick）：

```
add_bill_btn          记一笔
month_income_layout   月收入（可点）
month_pay_layout      月支出（可点）
month_balance_layout  月结余（可点）
budget_setting        预算设置
home_background       换背景
comment_btn           留言
tip_close / auto_tip / backup_tip / huawei_tip_close  各类提示条关闭
```

## 2. 统计页 `fragment_statistics.xml`

```
top_layout（横向滚动 Tab）
├─ normal_bill_btn   普通（分类统计）
├─ month_bill_btn    月度
├─ year_bill_btn     年度
├─ self_bill_btn     自定义
└─ btn_more
ViewPagerFixed statistics_pager   四个页面
```

- `fragment_statistics_normal.xml`：柱状图（近 N 日）+ 支出/收入合计与日均 + 资产饼图 + 分类列表 + 过滤勾选
- `fragment_statistics_month.xml`：月份列表（RecyclerView）+ 收支余三栏 + 柱状图（支出/收入/结余切换）+ 更多明细

## 3. 我的页 `fragment_my.xml`

```
ScrollView
├─ user_info_layout     头像 + 昵称 + 记账天数
├─ open_vip_layout      VIP 入口（一木商业模式，我们不做）
├─ tip_layout           提示条
├─ function_layout      功能宫格
│   ├─ auto_manager     自动记账
│   ├─ cycle_manager    周期记账
│   ├─ dream_list       梦想清单
│   ├─ ai_type_self     AI 相关
│   ├─ book_manager     账本管理
│   └─ …（后续 id 未采证）
```

> 说明：一木「我的」页含大量商业化入口（VIP、梦想清单、AI），我们只做记账，不复刻这部分。

## 4. 资产页 `fragment_asset.xml`（此前已采证）

```
净资产 banner（可隐藏）+ 存款/负债 + 卡片行（待报销/借出借入/投资/物品）+ 分组列表 + 右上资产设置
点击：净资产/存款/负债→构成弹窗；待报销→报销账户页；借出借入→借贷页；投资→持仓页；组头→类型统计
三个子页（activity_lend/stock/reimbursement）：tool_bar + 顶部两栏 + 列表
```

## 5. 日历页 `fragment_calendar.xml`（此前已采证）

```
tool_bar：月收入/月支出/月结余 + 返回今天 + 加账单 + 更多
CalendarLayout：月/周切换 + 年视图
格子（ActivityMonthView）：日期（今天画「今」）+ 农历/节日/节气 + -支出 + +收入
点某天：提示条 + 头部（日期/农历 + 收入/支出/结余）+ 还款提醒 + 账单列表
```

## 6. 当前实现与基准的差异（首页）

| 基准 | 当前实现 | 状态 |
|---|---|---|
| 顶部账本名 + 图标 | 无（账本切换在我的页） | 不一致 |
| 月份范围 + 箭头 | 只有「2026 年 11 月」标题 | 部分 |
| 加账单/搜索/更多 三个图标 | 一个全宽「添加一条新记账」按钮 | 不一致 |
| 列表含日期头 + 分类汇总行 | 只有账单行 | 不一致 |
| 月收入/支出/结余可点 | 不可点 | 不一致 |
| 下拉刷新 | 无 | 缺失 |
