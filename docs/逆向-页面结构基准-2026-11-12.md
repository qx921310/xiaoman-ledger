# 一木记账：页面结构基准（采证记录）

来源：`research/yimubill/apk-src`（反编译源码 + `resources/res/layout`）。
用途：作为「1:1 复刻」的事实基准。**未采证的项一律标注，不做推测。**

## 1. 首页 `fragment_home.xml`

```
RelativeLayout parent_layout
├─ tip_layout                 提示条（tip_image + 文案）
├─ DrawerLayout              右侧抽屉
│   ├─ JellyRefreshLayout → RecyclerView data_list     账单列表（可下拉刷新）
│   └─ right_drawer_layout
└─ BlurView tool_bar          浮动工具栏
    ├─ account_book_layout   账本图标 + 账本名            ← 当前账本在首页可见
    └─ tool_bar_right_layout
        ├─ month_range_layout 月份范围文字 + 箭头
        ├─ spin_kit           加载指示
        ├─ btn_add_bill       加账单
        ├─ btn_search         搜索
        └─ btn_more           更多
```

列表项（`item_bill_common_list.xml` / `item_bill_capital_flow.xml` / `item_bill_child_type.xml`）：

```
日期头：date_text + week_info + income + pay
账单行：icon + category + 金额（含 reimbursement/refund/discount 标记）
汇总行：total_layout + icon + name（分类小计）
```

首页点击行为（`HomeFragment.java` 的 @OnClick）：

```
add_bill_btn          记一笔
month_income_layout   月收入（可点）
month_pay_layout      月支出（可点）
month_balance_layout  月结余（可点）
budget_setting        预算设置
home_background       换背景
comment_btn           留言
tip_close / auto_tip / backup_tip / huawei_tip_close  各类提示条关闭
```

## 6. 当前实现与基准的差异（首页）

| 基准 | 当前实现 | 状态 |
|---|---|---|
| 顶部账本名 + 图标 | 无（账本切换在我的页） | 不一致 |
| 月份范围 + 箭头 | 只有「2026 年 11 月」标题 | 部分 |
| 加账单/搜索/更多 三个图标 | 一个全宽「添加一条新记账」按钮 | 不一致 |
| 列表含日期头 + 分类汇总行 | 只有账单行 | 不一致 |
| 月收入/支出/结余可点 | 不可点 | 不一致 |
| 下拉刷新 | 无 | 缺失 |

## 8. 补充采证（2026-11-12 第二轮）

### 8.1 首页列表项完整结构

首页用两个 adapter：`p0` → `item_bill_main_list.xml`，`l0` → `item_bill_main_detail_list.xml`。

`item_bill_main_list.xml`（简化行）：

```
total_layout
└─ time_layout  日期头
   ├─ date_check（选择框）+ date_info + day_flag（今天/昨天）+ week_info
   ├─ income_layout → income
   └─ pay_layout → pay
└─ bill_layout  账单行
   ├─ start_layout：icon + radio_button（多选）
   ├─ category + reimbursement + refund + discount（标记）
   ├─ second_layout：time + has_file_tag（附件）+ tag_one..tag_four + create_user（记账人）+ remark
   └─ cost_layout → 金额
```

`item_bill_main_detail_list.xml`（详细行，多出）：`old_cost`（优惠前金额）、`not_into_total`、`not_into_budget`。

分类汇总行 `item_bill_child_type.xml`：`total_layout + icon + name`。

**结论**：一木首页列表是「日期头 + 账单行」交织的一条列表，不是「独立汇总卡片 + 账单列表」。
