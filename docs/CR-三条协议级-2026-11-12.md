## P0

**任意一条冲突存在时，该账号所有待推送记录都停止推送。**

位置：`src/domain/sync-v2-runner.ts:57`

```ts
const pending = Object.keys(meta.conflicts).length ? [] : Object.entries(meta.pending)
```

复现（`tests/run-cr-sync-v2.cjs` 第 1 项，输出原文）：

```
1 条冲突 + 1 条待推送 → 实际推送条数 = 0
```

观察到的行为：`meta.conflicts` 非空即整体清空待推列表；冲突记录本身也不会再被尝试。

## P1

**1. `sync_operations` 只写不删。**

位置：`server/server.mjs:647`（读）、`:706`（写）。全文件无 DELETE/过期条件；每次推送产生一行。

**2. 无 `bookId` 的实体不参与代次校验。**

位置：`server/server.mjs:653`，`if (bookId)` 才检查 `generation`。
涉及 `splitGroup` / `splitMember` / `template` / `homeLoan` / `instalment` / `stockAsset` 等：不带 bookId 时按个人作用域处理，既不进入共享账本，也不被清空代次拦截。

**3. 冲突在界面上只有「保留本地版本」一个处理动作。**

位置：`src/features/settings.tsx`（`keepLocalConflict`）。未观察到放弃本地、双份保留、暂时忽略等路径。
