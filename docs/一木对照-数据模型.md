## 3. 多币种是怎么做的（结论）

1. **Currency 表**：`currencyCode`（USD）、`currencyName`（美元）、`symbol`（$）、`rate`（对本币汇率）、`positionWeight`
2. **Asset.currency**：每个账户有自己的币种，资产页按账户币种显示
3. **Bill 三件套**：`currencyInfo`（币种）+ `currencyAssetNumber`（外币金额）+ `currencyDiscountNumber`（外币优惠），`cost` 存**折合本币**后的金额
4. **换算**：`Currency.getCurrentRate(defaultCode)` —— 非默认币种时用 `rate × 交叉汇率`，说明汇率表是**相对默认币种**的，跨币种要两跳
5. 汇率可更新（`r0.j()` 返回汇率 map，说明有单独拉汇率的接口）

## 4. Cycle（周期记账）—— 差距最大

一木支持：`cycleType`（日/周/月/年）、`dateMode`、`monthDays[]`（一月多天）、`weekdays[]`（一周多天）、`monthLast`（每月最后一天）、`cycleTimes`/`addTimes`（共几次/已几次）、`endMode`/`end`/`pause`（结束/暂停）、`repayment`、`fromAssetId`+`toAssetId`（**周期转账**）、`serviceCharge`、`reimbursementId`、`nextDay`。

小满现在只有：`dayOfMonth` + 每月一次。**要补齐：每周 / 每年 / 每月多天 / 每月最后一天 / 暂停 / 次数上限 / 周期转账。**

## 5. Budget（预算）

一木：`budgetName` + `num`（额度）+ `addNum`（追加）+ `type`（周期类型）+ `year`/`month` + `startTime`/`endTime` + `bookId`；分类预算走关联表 `CategoryBudget`。
小满：`{month:'all', categoryId, amount}` —— **缺预算名称、周期类型（按年/季）、追加额度、起止时间**。

## 6. Transfer（转账）

一木：`cost`（转出）+ **`toCost`（实际到账）** + `serviceCharge`。
小满：`cost` + `serviceCharge`，**到账金额恒等于 cost**。
→ 跨境/跨币种转账时到账金额会不同，需要补 `toCost`。

## 7. Lend（借入借出）

一木：`fromCost`、**`interest`（利息）**、`outTime`/`inTime`、`repaymentAssetId`、`generalServiceBill`、`type`。
小满：`type`/`assetId`/`number`/`counterparty`/`time`/`remark`。
→ 缺**利息**与**还款账户**。

## 8. Reimbursement / Refund

- 一木 Reimbursement：`assetId`（付款账户）+ `reimbursementAssetId`（报销入账账户）+ `reimbursementNum` + `reimbursementNumbers[]`（分批明细）+ `end`
- 小满：`billId`/`assetId`/`number`/`detail`/`status`
- 一木 Refund：`refundNum` + `refundInfos[]`；小满：`number`

## 9. AccountBook / Tag

- 一木账本：`bookName`、`iconUrl`、`hide`、`currentBudgetId`、`shareUsers`、`notShowStock`、`notShowTransfer`、`positionWeight`
- 一木标签：独立实体（`tagName`、`color`、`parentTagId` 可嵌套、`hideBook`），账单只存 ID

## 10. 已完成

- ✅ **Transfer.toCost**：转出与到账可为不同金额（跨币种、对方扣费、手续费内扣）；删除时按 toCost 冲正并连带删除手续费账单
- ✅ **多币种**：Bill 三件套 + Currency 表 + Asset.currency + 记账页切换 + 汇率守卫/自修复（单测覆盖）
