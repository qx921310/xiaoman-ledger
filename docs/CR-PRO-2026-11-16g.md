- 级别：P2  
  位置：src/store.ts: deleteAsset/addAsset/updateAsset（约 1454、1467、1885 行）

  复现要点：在只读账本下尝试删除/新增/编辑账户，观察界面提示与实际资产列表不一致。  
  修复建议：将命令签名改为返回 boolean 或抛出明确错误，并让调用方依据返回值提示“只读账本不可操作”。

- 级别：P2  
  位置：src/features/assets.tsx（约 358、373 行）  
  现象：账户流水子页中月度净额 `g.net` 与行金额 `e.delta` 使用 `accountMoney` 转换，但前提是 `accountHistory` 返回的 `delta` 为账户币种；若其已折为本币，则会双重折算，导致显示金额错误。  
  复现要点：设置外币账户并有流水，查看账户子页，对比实际金额与显示。  
  修复建议：确认 `accountHistory` 返回的 `delta` 口径，确保只做一次币种转换；补充单元测试覆盖外币账户流水。

  复现要点：添加信用卡账户（余额为负），查看统计页“资产汇总”，确认负债是否缺失。  
  修复建议：核对产品口径，若应包含负债，改为按绝对值或净值处理并标注。

- 级别：P2

  复现要点：在简约视图下点击转账条目，观察是否出现编辑弹窗。  
  修复建议：对 `simpleView` 下的点击行为增加显式判断，禁止编辑入口，保持只读。

- 级别：待确认  
  位置：src/store.ts: addBill 内联校验（约 349-352 行）  
  现象：`bookId` 变量在 `currentBookId === 0` 且无 `patch.bookId` 时为 `undefined`，但最终 `bill.bookId` 被写成 `s.currentBookId`（0），而非 `undefined`；存在存在 silent 账本时拒绝，但无 silent 时允许，账单归属为 0。若 0 在后续同步中不被视作“未归属”，可能产生归属歧义。  
  复现要点：仅有本地账本或无 silent 账本时，在“全部账本”视图记账，检查新账单的 `bookId` 是否为 0。  
  修复建议：统一 `bookId` 为空值表示，避免 `0` 与 `undefined` 混用；记账时若处于“全部账本”，应强制要求显式选择账本或使用 `undefined` 并正确传递。
