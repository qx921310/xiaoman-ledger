## 踩过的坑（务必避开）

1. **不要按行号切片** —— 行号一错，文件结构就碎（我试过一次，`tsc` 报一堆语法错）
2. **不要用 `str.replace` 做多组件替换** —— 同一个锚点（如 `{readOnly ? (`）在多个组件里存在，会插到错误位置；`tsc` 还不一定报错
3. **不要 `git add -A`** —— 会扫进别人正在写的文件。今天两次把 Codex 的在途改动混进了 docs 提交
4. 组件间共享的闭包变量（`notify`、`user`、`me`、`readOnly`、`setTab`）需要显式改成 props，不能靠作用域
