# 逆向模块复刻对照（按模块逐字段）

对照来源：`research/yimubill/一木数据模型-APK.md`（一木 6.7.2 实体字段）。
判断标准：**字段存在且参与业务逻辑**才算复刻；只声明不用的不算。

## 结论速览

| 模块 | 字段复刻 | 说明 |
|---|---|---|
| 记账（Bill） | ~85% | 缺 AA 分摊明细、优惠金额、报销结束标记 |
| 账户（Asset） | ~70% | 缺账户所属账本、自定义图标、报销额度 |
| 分类（Category） | 100% | 104 个分类全复刻（一木是服务端下发，我们内置打包） |
| 账本（AccountBook） | ~60% | 缺账本图标/排序/关联预算 |
| 周期（Cycle） | ~65% | 缺次数上限、结束日期、结束方式 |
| 预算（Budget） | ~30% | 只有月度额度，缺**预算周期化**（差距最大） |
| 标签（Tag） | ~70% | 有颜色/父标签名，缺嵌套 UI、隐藏 |
| 报销（Reimbursement） | ~90% | 支持分次，缺报销结束标记 |
| 退款（Refund） | 100% | 含账本、币种、本币金额 |
| 转账（Transfer） | 100% | 含手续费、到账金额、关联手续费账单 |
| 借贷（Lend） | ~90% | 含利息、部分还款，缺还款计划 |

## 一、记账（Bill）

**一木字段**：assetId billId billShareInfo billType bookId childCategoryId cost currencyAssetNumber currencyDiscountNumber currencyInfo discountNumber displayAsSelf fromUserId inAssetTime notIntoBudget notIntoTotal parentCategoryId poiAddress recordTime reimbursement reimbursementEnd remark tags time totalAddress updateTime userId

**已复刻**：assetId、billId、billType、bookId、childCategoryId、cost、currencyAssetNumber、currencyDiscountNumber、currencyInfo、displayAsSelf、fromUserId、inAssetTime、notIntoBudget、notIntoTotal、parentCategoryId、poiAddress、recordTime、reimbursement、remark、tags、time、totalAddress、updateTime、userId

**未复刻**：
- **billShareInfo（AA 分摊明细）** —— 我们同名字段只存分类/账户快照，不是分摊
- **discountNumber（原币优惠金额）** —— 只有 `currencyDiscountNumber`
- **reimbursementEnd（报销结束标记）**

**我们多出的**：syncId、memberNo、sequenceNo、displayId、cycleId、files、accountAmount、accountCurrency、ownerId

## 二、账户（Asset）

**一木字段**：assetIcon assetId assetName assetNumber assetType bookId cardCode currency groupName hide iconUrlNight inAccountDate intoTotalAsset outAccountDate outDayNotNext positionWeight reimAssetNumber remark shareQuotaAsset showBook simpleName totalQuota updateTime userId

**未复刻**：assetIcon（自定义图标）、**bookId（账户所属账本）**、iconUrlNight、outDayNotNext、reimAssetNumber、shareQuotaAsset、showBook、simpleName

## 三、周期（Cycle）

**一木**：addTimes cycleTimes cycleEndDate end endMode lastAddTime nextDay pause 等

**未复刻**：**cycleTimes（共记几次）**、addTimes、cycleEndDate（结束日期）、end/endMode（结束方式）、nextDay、pause（我们用 enabled 近似）

**我们多出的**：skipDates（跳过某一期）、monthOfYear、skipDates

## 四、预算（Budget）——差距最大

**一木**：budgetId budgetName type month year num addNum positionWeight startTime endTime bookId

**我们**：month、categoryId、amount、updateTime

**未复刻**：预算周期化（年/季/自定义起止）、预算名称、追加额度（addNum）、预算关联账本、排序

## 五、标签（Tag）

**一木**：check color hide hideBook parentTagId positionWeight tagId tagName updateTime userId

**未复刻**：**parentTagId（真实嵌套，我们用 parentName 字符串）**、check、hide、hideBook、userId

## 六、账本（AccountBook）

**一木**：accountBookId bookName createTime currentBudgetId 等

**未复刻**：currentBudgetId（账本关联预算）、账本图标/颜色/排序

## 七、模块级差异（非字段）

| 能力 | 一木 | 我们 |
|---|---|---|
| 分类来源 | 服务端下发 | 内置打包 104 个 |
| 统计维度 | 收支图、分类图、按日报表、账户收支、标签统计 | 分类条形图 + 预算（缺按日、账户、标签维度） |
| 搜索 | 金额范围、标签、日期范围 | 关键词 + 分类 + 账户 |
| 账户历史流水页 | 有 | 无 |
| 附件 | 账单关联图片/票据 | 仅字段，无上传与预览 |
| 主题皮肤 | 多套 | 无 |

## 八、如果要继续补，优先级

1. **AA 分摊**（`billShareInfo` 的真实语义）——家庭账本高频
2. **预算周期化**（年/季/起止/追加）——目前只有月度
3. **周期次数与结束**（记满 N 次自动停、指定结束日期）
4. **账户绑定账本**（多账本时账户该归属哪个）
5. **统计补维度**（按日趋势、账户维度、标签维度）
6. **标签嵌套 UI**（数据已用 parentName 近似）
